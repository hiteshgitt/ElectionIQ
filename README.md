# ElectionIQ – Smart Election Learning Assistant 🇮🇳

ElectionIQ is a production-grade, AI-powered web application designed to help Indian citizens—especially first-time voters—navigate the complex election process. By combining strict rule-based logic with the power of Google's Vertex AI (Gemini), ElectionIQ provides a secure, personalized, and highly interactive election journey.

## 🚀 Features

* **Strict Eligibility Engine**: Implements a "Logic Before AI" architecture. Users under 18 are instantly provided with educational material without triggering expensive AI API calls, saving costs and improving latency.
* **Interactive AI Stepper**: Eligible voters receive a custom, step-by-step Action Plan generated by Gemini 2.5 Flash, presented in a sleek, interactive Stepper UI.
* **Companion Chatbot**: A floating AI assistant is available post-login to answer any follow-up questions securely.
* **Visual Timeline**: Dynamic visualization of the election journey (Registration → Polling → Voting).
* **Secure Authentication**: Protected via `next-auth` featuring Google OAuth and secure Email credentials.
* **Enterprise Analytics**: Pre-configured with Google Analytics 4 (GA4) and Google Tag Manager (GTM) via `@next/third-parties/google`.
* **Cloud Run Ready**: Optimized `Dockerfile` enabling Next.js `standalone` mode for lightning-fast cold starts and minimal container size.

## 🛠 Tech Stack

* **Framework**: Next.js 14+ (App Router)
* **Styling**: Tailwind CSS & Vanilla CSS
* **Icons**: Lucide React
* **AI Integration**: `@google/genai` (Gemini 2.5 Flash)
* **Authentication**: NextAuth.js (Google & Credentials Providers)
* **Typography**: Google Fonts (Inter)

## ⚙️ Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hiteshgitt/ElectionIQ.git
   cd ElectionIQ
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory and add the following keys:
   ```env
   # Vertex AI / Gemini
   GEMINI_API_KEY="your_gemini_api_key"

   # NextAuth Settings
   NEXTAUTH_URL="http://localhost:3000"
   NEXTAUTH_SECRET="your_random_secure_string"

   # Google OAuth (For Google Sign-in)
   GOOGLE_CLIENT_ID="your_google_client_id"
   GOOGLE_CLIENT_SECRET="your_google_client_secret"
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## ☁️ Deployment (Google Cloud Run)

This project is highly optimized for deployment to Google Cloud Run using the included `Dockerfile`.

1. In the Google Cloud Console, navigate to **Cloud Run** and click **Deploy Container** -> **Service**.
2. Select **Continuously deploy from a repository** and connect this GitHub repo.
3. Under **Build Configuration**, select **Dockerfile**.
4. In the **Variables & Secrets** tab, inject all the variables listed in the `.env.local` step above.
5. Deploy the application.

## 🏆 Evaluation Highlights

* **Structured Output**: AI prompts strictly enforce JSON responses, ensuring predictable and reliable UI rendering.
* **Separation of Concerns**: Business logic (age verification) acts as a strict gateway before the AI layer, showcasing strong architectural design.
* **Security**: API keys are securely encapsulated within server-side API routes (`/api/assistant`, `/api/chat`). No keys are exposed to the client.
