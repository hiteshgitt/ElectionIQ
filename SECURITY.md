# Security Policy

## Supported Versions

The following versions of ElectionIQ are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within ElectionIQ, please do not open a public issue. Instead, send an email to security@electioniq.com. All security vulnerabilities will be promptly addressed.

Please include the following in your report:
- Type of issue (e.g., XSS, SQLi, etc.)
- Location of the issue
- Steps to reproduce
- Potential impact
